---
title: Tabs, panels and shortcuts
description: Split editors, drag tabs between groups, the activity bar, the bottom panel and the keyboard shortcuts.
---

Stave's workspace is a grid of **groups**, each holding a stack of **tabs**. Every file opens in a tab. Tabs can be dragged between groups, and groups can be split side by side or one above the other.

## Splitting

- **⌘\\**: split the editor to the right.
- **⌘⇧\\**: split the editor down.

## Moving tabs

Drag a tab's header onto another group. Dropping it on:

- **the tab strip** puts the tab at that position.
- **the top, bottom, left or right of a group** splits that group and puts the tab in the new half.
- **the middle of a group** adds it to that group's tabs.
- **the left or right edge of the window** makes a new column.

## Activity bar

The narrow bar on the far left switches the side panel:

- **Files**: your project's files and folders.
- **Search**: search across every file.
- **History**: [Version History](/concepts/projects/#version-history).
- **Library**: sounds, your audio and ready-made visuals. See [Library](/studio/library/).
- **Console**: errors and warnings, with a count badge when there are any.

**⌘B** shows or hides the side panel.

## Bottom panel

The panel at the bottom holds the studio: **[Timeline](/studio/timeline/)**, **[Pattern](/studio/pattern/)** and **[Mixer](/studio/mixer/)**. Drag its top edge to resize it. It hides while the active tab is a visual file.

## Keyboard shortcuts

| Shortcut | What it does |
|---|---|
| **⌘Enter** | Play / evaluate |
| **⌘.** | Stop |
| **⌘⇧P** | Show all commands |
| **⌘P** | Quick open a file |
| **⌘⇧F** | Search in files |
| **⌘⇧D** | Search the documentation |
| **⌘/** | Keyboard shortcuts |
| **⌘N** / **⌘O** | New project / open project |
| **⌘Z** / **⌘⇧Z** | Undo / redo |
| **⌘B** | Show or hide the side panel |
| **⌘=** / **⌘-** | Bigger / smaller editor text |
| **⌘⌥Z** | Zen mode |

These work while your cursor is in the code, too. Where the code editor has a key of its own, the editor's wins: in the code, **⌘/** comments out the line and **⌘Z** / **⌘⇧Z** undo and redo your typing. To open the shortcut list from the code, press **⌘⇧P** and run **Keyboard Shortcuts**. On Windows and Linux, a **Ctrl+Alt** shortcut such as Zen mode doesn't run from the code, because Ctrl+Alt is the AltGr key that types characters like ż; use the menu instead.

On Windows and Linux, use **Ctrl** for **⌘**. **⌘/** lists every shortcut. Click one to change it, or use **Reset all keybindings** to go back to the defaults. Editor keys like Play and Stop can be searched there but not changed. The Timeline has its own keys for sections; see [Timeline](/studio/timeline/#sections).

## Zen mode

**⌘⌥Z** enters Zen mode, for performing. The activity bar and side panel hide, and the browser goes full screen. The menu bar stays, so you can always get back out with the mouse: **View › Exit Zen Mode**. Press **Esc** to leave. Every command still works from **⌘⇧P**.
